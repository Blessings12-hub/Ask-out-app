No music on the site anymore
-----------------------------
The Spotify embed/chip has been removed from index.html and script.js —
the site is silent now. The unused MP3 that was already sitting in this
folder (see below) still isn't referenced by anything.

If you ever want music back, either:
- Add a Spotify embed again (find a track → Share → Copy embed link), or
- Use a file you genuinely have rights to (purchased, royalty-free, or
  Creative Commons) and wire up a local `<audio>` tag — ask me and I'll
  add it.

A note about the old MP3 in this folder
-----------------------------------------
The MP3 that was here (downloaded from a lyrics/rip site) was never wired
up — renaming it to `Song.mp3` didn't change that, it's byte-for-byte the
same file as before. It's still someone else's copyrighted commercial
recording, and since this site is meant to go live on a public URL,
hosting/serving it from your own domain would still be music piracy
regardless of the filename. It's just sitting in this folder unused.
